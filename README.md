# HavenAid

HavenAid is a humanitarian response platform prototype built with React, TypeScript, Vite, and Tailwind CSS. It helps people report urgent needs, track case updates, and support crisis response coordination.

## Features

- Crisis reporting workflow
- AI-assisted triage simulation
- Report tracking and status updates
- Admin dashboard for response coordination
- Donation flow to verified humanitarian organizations
- Arabic and English UI support
- Responsive mobile-first layout

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev -- --host 0.0.0.0
   ```
3. Open the site in the browser on the Vite local port.

## Production Build

```bash
npm run build
```

## Project Notes

This is a prototype designed to demonstrate a realistic humanitarian response experience. It does not collect payment information or fake user financial data.
